# Screenshot guide

[한국어](README.md) · English

## Capture scope and privacy

All 21 screenshots were recaptured on 2026-11-07 from the real HTML/CSS/JavaScript of version **1.0.11**, in light and dark mode (42 files), with isolated browser API fixtures. No operational Home Assistant or Drive settings/files were changed. Viewports were 1440px desktop and 390px mobile; each dark-mode image has the same name with `-dark` (e.g. `roadviewer-overview-dark.png`), and the READMEs show the one matching the reader's theme.

Device ID `DEMO-DEVICE`, route hash `0000000000`, pairing code `DEMO0123DEMO4567DEMO8901`, capacities, times, tags, bookmarks, and vehicle values are examples. They are not actual credentials, device tokens, or private driving logs. The code cannot pair a device. The log-list thumbnails are generated example pictures. These layout examples do not replace real-account or playback validation.

For the three introduction photos (video with vehicle graphs, road view, wide camera), only the video area of the previous photos was cropped, turned into a still clip, and composited into the new replay screen. The lane and vehicle drawings inside the picture were already part of the old photos, so the overlay is switched off. Speed, graph, and road-view values are fixtures and do not match the scene. The UI detail captures use Korean; the English documents share these images.
