한국어 · [English](README.en.md)

## 촬영 기준과 개인정보

2026-11-05에 **0.13.3** 버전 표기의 main(`6631968`)의 실제 HTML·CSS·JavaScript로 UI 상세 화면 18장을 촬영했습니다. API 응답은 격리된 브라우저에서 예시 데이터로 대체했으며 운영 HA·Google Drive의 설정·파일을 변경하지 않았습니다. 데스크톱 1440px, 모바일 390px 화면을 사용했습니다.

장치 ID `DEMO-DEVICE`, 주행 식별자의 해시 `0000000000`, 페어링 코드 `DEMO0123DEMO4567DEMO8901`, 저장공간·시각·태그·북마크 값은 예시입니다. 실제 인증 키·장치 토큰·개인 주행 로그가 아니며 코드로 페어링할 수 없습니다. 그림은 UI 배치 예시이며 실제 계정 연결·영상 재생의 검증 결과를 대신하지 않습니다.

사용자가 선택한 주행·와이드 소개 사진 3장은 교체하지 않았습니다. 이 사진은 기능 소개용으로 이전 UI·버전이 포함될 수 있습니다. 상세 화면은 한국어 UI이며 영어 문서도 동일 이미지를 사용합니다.
