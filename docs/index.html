HOME ASSISTANT 앱

openpilot 주행 기록을
내 Home Assistant에서 다시 봅니다

Road Viewer는 openpilot 주행 로그(rlog.zst)와 카메라 영상을 Home Assistant에 올려 재생하고, 차선·선행 차량·조향 같은 주행 데이터를 영상과 함께 시각화하는 자체 호스팅 앱입니다. 기록은 사용자의 Home Assistant 기기에 저장됩니다.

GitHub 저장소 보기개인정보처리방침

주요 기능

Home Assistant 사이드바(Ingress)에서 바로 사용하며, 별도의 외부 서버나 Road Viewer 계정이 필요하지 않습니다.

주행 영상·로그 조회

openpilot 장치나 PC에서 로그와 영상(qcamera, 전방·광각 카메라)을 올리면 주행·구간별로 정리해 태그, 북마크와 함께 보여 줍니다. 원본 로그와 MP4 영상을 내려받을 수 있습니다.

주행 데이터 시각화

영상과 시간을 맞춰 차선, 도로 경계, 선행 차량과 레이더 대상을 겹쳐 보여 주고, 조향과 속도 같은 텔레메트리를 함께 표시하며, 주행 장면을 위에서 본 도로 화면으로 재구성합니다.

주행 경로 지도

로그의 GPS로 주행 경로를 지도에 그립니다. 전체 지도, 주행 지도, 재생 화면의 지도 탭과 영상 위 작은 지도에서 재생 위치를 함께 봅니다. 지도는 OpenStreetMap 기반 OpenFreeMap을 사용합니다.

저장공간 관리와 아카이빙

로컬 사용량 한도와 정리 정책을 정할 수 있고, 오래된 기록을 NAS 또는 사용자의 Google Drive에 보관할 수 있습니다. 아카이빙은 기본적으로 꺼져 있습니다.

Google Drive 아카이빙

사용자가 직접 설정한 경우에만 동작하는 선택 기능입니다. Google 로그인 화면에 표시되는 앱 이름 harv-gdrive는 Road Viewer의 이 기능에서 쓰는 OAuth 클라이언트입니다.

  • Google의 기기 인증(코드 입력) 방식으로 연결하며, 요청하는 권한은 drive.file 하나입니다. Road Viewer가 만든 폴더와 파일만 다룰 수 있고, 같은 계정의 다른 Drive 파일은 읽거나 바꿀 수 없습니다.
  • 사용자의 Drive에 전용 폴더를 만들어 주행 로그와 영상 파일을 올리고, Drive가 알려 주는 체크섬으로 사본을 검증합니다.
  • 기본은 로컬 파일을 그대로 두는 복제 모드입니다. 로컬 원본을 지우는 이동 모드는 사용자가 두 가지 옵션을 모두 설정해야만 켜집니다.
  • 통신은 사용자의 Home Assistant 기기와 Google 사이에서만 일어납니다. Road Viewer 개발자는 사용자의 Google 데이터나 토큰을 받는 서버를 운영하지 않습니다.

자세한 데이터 처리 방식은 개인정보처리방침을 확인하세요.

설치

  1. Home Assistant에서 설정 → 애드온 → 애드온 스토어 → 저장소를 엽니다.
  2. https://github.com/Qualified4/roadviewer-ha를 추가합니다.
  3. Road Viewer를 설치하고 시작한 뒤 사이드바에서 엽니다. 자세한 사용법은 저장소 문서를 참고하세요.
