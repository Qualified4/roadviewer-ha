브라우저로 장치 업로드 테스트

openpilot 없이 이 브라우저를 테스트 장치로 연결합니다. 실제 서버에 장치를 등록하고 파일을 업로드합니다.

이 파일을 직접 열지 말고 Road Viewer의 HTTPS 주소 뒤에 /api/device/test를 붙여 접속하세요.

1. 테스트 장치 연결

Home Assistant의 로그 업로드 → 외부 장치 연결 → 새 장치 연결에서 발급한 코드를 입력하세요. 키는 메모리에만 보관하며, 새로고침하면 다시 페어링해야 합니다. 테스트 후 해당 장치를 Revoke할 수 있습니다.

연결된 장치 없음

2. 업로드 파일 준비

원본 이름이 route--구간--rlog.zst 또는 route--구간--qcamera.ts인 파일을 선택하세요. 구간마다 rlog.zst가 필요합니다. 이 테스트 페이지는 브라우저 메모리 부담을 줄이기 위해 파일당 64 MiB까지 지원합니다.

가상 파일은 전송 검증용입니다. 완료 처리하면 목록에 등록되지만 유효한 주행 데이터가 아니므로 변환은 실패합니다. 실제 로그는 기존 변환 설정에 따라 처리됩니다. 선택한 저장 정책도 적용되며, 자동 삭제 정책이면 기존 미고정 주행이 삭제될 수 있습니다.

  • 파일을 선택하거나 가상 파일을 준비하세요.

3. 전송과 이어올리기

세션 없음

전송 대기

일시정지는 현재 조각의 응답을 받은 뒤 멈춥니다. 네트워크 오류 후에는 다시 업로드를 누르면 서버에 저장된 위치부터 이어갑니다. 서버를 재시작했다면 이 페이지를 유지한 채 세션 생성 / 복구를 누르세요. 완료 처리 후 로그는 Home Assistant 목록에서 확인·삭제할 수 있습니다.

4. 인증 차단 확인

잘못된 서명은 401, 같은 nonce의 재사용은 409로 차단되어야 합니다. 재전송 검사는 먼저 현재 배치로 정상 세션을 생성하거나 복구하므로 저장공간 예약이 생길 수 있습니다.
