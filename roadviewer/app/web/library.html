    제한은 원본·변환·임시 파일을 합산하며 업로드 전에 배치 전체 용량을 예약합니다. 저장 한도를 낮춰도 즉시 삭제하지 않습니다. 변환 결과의 크기는 달라질 수 있어 파일시스템의 강제 용량 제한은 아닙니다.

    처리 상태

    미변환
    로그와 보관 영상을 유지한 상태입니다. 변환하면 재생할 수 있습니다.
    대기 중
    변환 순서를 기다립니다.
    처리 중
    로그 분석 또는 영상 변환을 진행합니다.
    재생 가능
    변환이 완료되어 재생할 수 있습니다.
    변환 실패
    변환 버튼으로 다시 시도할 수 있습니다.

    로그 작업

    재생·변환 버튼 옆 펼침 메뉴(⌄)에서 선택합니다. 변환 전에는 제거가 표시되지 않습니다.

    변환
    재생용 데이터를 생성합니다.
    제거
    분석·그래프와 다시 만들 수 있는 MP4를 삭제합니다. 원본 로그·TS 및 TS 없이 보관하는 MP4는 유지합니다.
    로그 다운로드
    업로드한 ZST 로그를 내려받습니다.
    영상 다운로드
    TS가 있으면 원본 TS를, TS 없이 MP4만 보관 중이면 MP4를 내려받습니다.
    완전 삭제
    원본과 변환 데이터를 모두 삭제합니다.

    수동으로 제거한 항목은 자동으로 다시 변환되지 않습니다. 재시작 후에도 직접 변환해야 합니다.

    로그 이름과 복사

    첫 식별자의 앞자리 0과 뒤쪽 식별자를 생략해 짧게 표시합니다. 00000395--0d0eda17c5--7은 395 / 구간 7로 보입니다. 이름 옆 복사 버튼은 생략하지 않은 전체 이름을 확장자 없이 복사합니다.

    구간 고정

    재생·변환 옆 핀 아이콘은 해당 구간만 자동 삭제에서 보호합니다. 다시 누르면 해제하며, 재시작 후에도 유지됩니다. 이후 업로드한 다른 구간에는 적용되지 않습니다. 수동 완전 삭제는 고정한 구간도 삭제합니다.

    기존 주행 단위 고정은 저장된 각 구간의 고정으로 이전됩니다.

    Home Assistant 연결을 통해 접근합니다. 업로드한 원본과 변환 데이터는 앱 저장소에 보관됩니다.

    로그 일괄 관리

    변환은 미변환·실패 항목을 대기열에 넣고 설정한 동시 처리 개수를 따릅니다. 제거는 분석·그래프와 재생성 가능한 MP4만 삭제합니다. 완전 삭제는 보관 파일까지 삭제하며 되돌릴 수 없습니다. 대기·처리 중인 항목은 제거할 수 없습니다.
