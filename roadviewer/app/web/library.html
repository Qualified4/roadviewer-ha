    저장공간 관리

    제한은 원본·변환·임시 파일을 합산하며 업로드 전에 배치 전체 용량을 예약합니다. 저장 한도를 낮춰도 즉시 삭제하지 않습니다. 변환 결과의 크기는 달라질 수 있어 파일시스템의 강제 용량 제한은 아닙니다.

    설정을 불러오는 중입니다.

    자동 삭제는 주행 ID가 같은 모든 구간을 함께 삭제합니다. 업로드 중이거나 대기·변환 중인 주행, Pin으로 고정한 주행은 보호합니다. 오래된 순서는 최초 업로드 시각을 기준으로 합니다. 수동 완전 삭제는 고정 여부와 관계없이 가능합니다.

    외부 장치 연결

    장치는 HTTPS 주소로 직접 업로드합니다. 애드온 설정에서 장치 API와 TLS 인증서를 설정하고 네트워크 포트를 열어 주세요. Home Assistant Ingress 화면은 외부 장치 포트에 공개되지 않습니다.

    openpilot 없이 테스트하려면 외부 HTTPS 주소 뒤에 /api/device/test를 붙여 브라우저에서 여세요. 테스트 페이지에서도 페어링 코드가 필요합니다.

    로그 이름과 복사

    로그 목록과 재생 화면에서는 첫 번째 식별자의 앞자리 0과 뒤쪽 식별자를 생략해 이름을 간단히 표시합니다. 예를 들어 00000395--0d0eda17c5--7은 395 / 구간 7로 표시됩니다. 이름 옆 복사 버튼을 누르면 생략하지 않은 전체 이름 00000395--0d0eda17c5--7이 확장자 없이 클립보드에 복사됩니다.

    로그 작업

    목록에는 재생 또는 변환 버튼과 옆의 펼침 버튼(⌄)이 표시됩니다. 펼침 메뉴에서 제거·로그 다운로드·영상 다운로드·완전 삭제를 선택합니다. 변환 전에는 제거가 표시되지 않으며, 완전 삭제는 모든 상태에서 사용할 수 있습니다.
