    장치 연결 및 테스트 안내

    Home Assistant Ingress 화면은 외부 장치 포트에 공개되지 않습니다. openpilot 없이 테스트하려면 외부 HTTPS 주소 뒤에 /api/device/test를 붙여 브라우저에서 여세요. 테스트 페이지에서도 페어링 코드가 필요합니다.

    변환 방식과 화면 모드를 관리하세요.

    변환 기본 설정

    변경하면 바로 저장됩니다

    설정을 확인하는 중입니다.

    동시에 처리할 로그 개수입니다.

    영상 보관 방식새로 완료하는 변환은 q·f·e 영상을 재압축 없이 MP4로 포장하고, 전체 디코딩 없이 압축 데이터·헤더·프레임 수·시간을 검증한 뒤 원본 TS·HEVC를 정리합니다. 검증에 실패한 영상은 원본을 유지합니다. 자동 변환이 꺼져 있으면 새 업로드는 파일만 보관하며, 직접 변환한 영상은 MP4로 보관합니다. 원본 로그는 유지합니다. 다운로드 팝업에서 MP4 또는 원본 형식을 선택할 수 있습니다.

    화면 모드

    자동은 기기의 라이트·다크 설정을 따릅니다. 이 브라우저에만 저장됩니다.

    변환하면 무엇이 만들어지나요?

    재생용 데이터와 영상 보관 방식
    펼치기접기

    업로드한 파일을 재생 화면에서 볼 수 있도록 준비하는 작업입니다. 원본 로그는 유지하고, 영상은 MP4 한 벌로 보관합니다.

    로그 분석
    주행 상황·감지 차량·차량 정보 그래프 등 재생용 데이터를 만듭니다.
    영상 변환
    qcamera의 H.264와 f·e의 HEVC 코덱을 유지한 채 MP4로 포장합니다. 카메라별 로그 시간으로 동기화하며 고화질 전방 영상을 우선 재생합니다. HEVC 재생에는 브라우저와 기기의 HEVC 지원이 필요합니다. 재생에 실패하면 저화질 전방 영상 등 사용 가능한 다른 영상으로 전환을 시도하며, 대체할 영상이 없으면 오류를 안내합니다.

    영상 없이 로그만 변환할 수도 있습니다. 자동 변환을 끄면 새 자동 변환을 중지하고 업로드한 파일을 보관합니다. 이미 처리 중인 작업과 수동으로 요청한 변환은 계속됩니다. 목록의 변환 버튼으로 원하는 로그를 직접 처리할 수 있습니다.

    상태 및 파일 관리 안내

    처리 상태, 다운로드, 제거와 완전 삭제의 차이
    펼치기접기

    처리 상태

    미변환
    로그와 보관 영상을 유지한 상태입니다. 변환하면 재생할 수 있습니다.
    대기 중
    변환 순서를 기다립니다.
    처리 중
    로그 분석 또는 영상 변환을 진행합니다.
    재생 가능
    변환이 완료되어 재생할 수 있습니다.
    변환 실패
    변환 버튼으로 다시 시도할 수 있습니다.

    로그 작업

    재생·변환 버튼 옆 펼침 메뉴(⌄)에서 선택합니다. 미변환 항목에는 제거가 표시되지 않으며, 처리 중에는 제거할 수 없습니다.

    변환
    재생용 데이터를 생성합니다.
    제거
    대기 중인 항목은 변환 예약을 취소합니다. 분석·그래프와 원본으로 다시 만들 수 있는 MP4를 삭제하며, 원본 로그·영상 및 원본 없이 보관하는 MP4는 유지합니다.
    다운로드
    팝업에서 로그와 카메라 영상, MP4·원본 형식(HEVC·TS)을 골라 받습니다. 선택한 파일이 하나면 그대로, 여러 개면 ZIP으로 받고, 각 파일 옆의 받기로도 개별 다운로드할 수 있습니다. 없는 카메라는 제외합니다. 원본 형식은 재압축 없이 다시 만들며 화질은 같지만 업로드한 파일과 바이트까지 같지는 않습니다.
    완전 삭제
    원본과 변환 데이터를 모두 삭제합니다.

    수동으로 제거한 항목은 자동으로 다시 변환되지 않습니다. 재시작 후에도 직접 변환해야 합니다.

    로그 이름과 복사

    첫 식별자의 앞자리 0과 뒤쪽 식별자를 생략해 짧게 표시합니다. 00000395--0d0eda17c5--7은 395 / 구간 7로 보입니다. 이름 옆 복사 버튼은 생략하지 않은 전체 이름을 확장자 없이 복사합니다.

    구간 고정

    재생·변환 옆 핀 아이콘은 해당 구간만 자동 삭제에서 보호합니다. 다시 누르면 해제하며, 재시작 후에도 유지됩니다. 이후 업로드한 다른 구간에는 적용되지 않습니다. 일괄 제거·완전 삭제는 기본적으로 고정한 구간을 제외합니다. 로그 관리에서 ‘고정 항목도 삭제’를 켜면 포함됩니다. 개별 로그 메뉴에서는 직접 제거·완전 삭제할 수 있습니다.

    기존 주행 단위 고정은 저장된 각 구간의 고정으로 이전됩니다.
