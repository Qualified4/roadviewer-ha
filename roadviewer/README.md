# Road Viewer

한국어 · [English](README.en.md)

현재 기능 안내: **1.3.11**

openpilot 로그와 전방·와이드 카메라 영상을 Home Assistant 안에서 함께 재생하고 분석하는 앱입니다.

## 빠른 시작

**업로드** 탭에서 **파일 추가 또는 드래그 앤 드롭 → 업로드 → 변환 → 재생** 순서로 사용합니다. 자동 변환은 기본으로 켜져 있습니다. 화면은 **로그 · 업로드 · 저장공간 · 장치 · 설정** 탭으로 나뉘며 휴대폰에서는 하단 탭 바로 표시합니다.

같은 구간의 `rlog.zst`와 필요한 영상(`qcamera.ts`, 고화질 전방 `fcamera.hevc`, 와이드 `ecamera.hevc`)을 선택하세요. 로그만 올릴 수도 있습니다. 같은 구간의 rlog와 카메라별 MP4를 함께 재업로드할 수 있지만 영상만 단독 등록할 수는 없습니다. qcamera MP4는 H.264, 고화질·와이드 MP4는 HEVC여야 합니다. 여러 구간을 함께 선택할 수 있으며, 모바일 파일 선택창이 다중 선택을 지원하지 않으면 하나씩 추가하세요.

## 주요 기능

- 영상·주행 상황·차량 정보 그래프의 동기 재생과 최대 4배속
- 전방·와이드 영상 전환과 카메라별 보정 기반 겹쳐보기, 연결별 기본 화질(모바일 데이터는 저용량 qcamera, 와이파이·유선은 고화질 전방)
- 차선·모델 경로·레이더 감지점, LF·FF·RF 박스와 BSD·방향지시등 표시
- 간결한 앱 바(출발 시각 · 구간 k (i/N), 보기·⋯ 메뉴)와 하단에 떠 있는 재생 바(구간 띠, 자동 제어·운전자 개입 트랙, 북마크 마커)
- 자동·좌우·상하 배치와 화면 폭 조절, 자동·라이트·다크 화면 모드(영상 영역은 항상 어두움)
- 그래프 24종의 선택·순서 변경·초기화와 카메라 설치 정보 확인
- 자동·수동 변환, 최대 4개 동시 처리, 재압축 없는 MP4 보관
- 영상 나중에 추가, MP4·원본 형식 다운로드
- 구간 태그와 북마크 탭의 장면 북마크
- GPS 주행 경로 지도: 로그 탭의 **목록 | 지도** 전체 지도, 주행 지도, 재생 화면 **지도** 탭과 영상 위 작은 지도(OpenFreeMap, API 키 불필요). Drive에만 있는 로그는 선택해서 경로를 채움
- 검색·필터 칩과 날짜별 주행 카드(썸네일, 출발 시각, 구간 상태 막대, 자동 제어 비율·개입 횟수, 기본 접힘), 구간별 저장 위치(로컬·Drive·NAS) 표시. 이전·아카이빙 로그의 썸네일·출발 시각은 백그라운드에서 채움
- 구간별 핀 고정, 목록 안 선택 모드의 일괄 태그·다운로드·변환·제거·완전 삭제, 재생 화면 ⋯ 메뉴의 제거·다운로드·완전 삭제, 저장공간 한도와 자동 정리
- 실험 기능: 오래된 기록을 Google Drive 또는 NAS로 복사·이동하는 아카이빙, Drive 연결·연결 해제
- 선택적 HTTPS 장치 업로드와 페어링
- AI 에이전트용 MCP 서버 [roadviewer-mcp](https://github.com/Qualified4/roadviewer-mcp)(별도 프로젝트, 기존 Ingress 인증과 API만 사용)

## 파일을 정리할 때

**제거**는 분석·그래프와 다시 만들 수 있는 MP4를 지우고 원본 로그·TS·HEVC 및 카메라별 유일한 MP4를 유지합니다. 대기 작업은 취소하며 처리 중인 항목은 제거할 수 없습니다. **완전 삭제**는 해당 구간의 파일을 모두 지웁니다.

로그 탭의 **선택** 버튼(터치 화면은 구간 길게 누르기)으로 목록 안 선택 모드를 시작하고 하단 작업 바에서 일괄 처리합니다. 고정된 구간은 기본적으로 제거·완전 삭제에서 제외되며, **고정 포함**을 켜면 포함됩니다. 선택 모드를 다시 시작하면 꺼짐으로 돌아갑니다.

Drive MOVE 이외의 기존 저장 정책에서는 예약만으로 삭제하지 않고 업로드 수신·검증 뒤 등록할 때 오래된 적격 구간을 정리합니다. 고정·대기·처리 중·Drive 파일이 연결된 기록은 보호합니다.

웹 UI는 Home Assistant Ingress로 접속합니다. 외부 장치 API는 기본적으로 꺼져 있으며 필요한 경우에만 앱 내부에서 HTTPS 포트를 설정합니다.

**원본 로그·영상·변환 결과는 Home Assistant 앱 백업에서 제외됩니다.** 보관할 원본은 별도로 유지하세요. 처리·저장 정책·장치 인증 설정은 백업에 포함됩니다.

자세한 사용법은 앱의 **문서** 탭 또는 [사용 설명서](DOCS.md) · [English](DOCS.en.md), 버전별 변경은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

## 지원 플랫폼

`amd64`(Intel/AMD 64비트)와 `aarch64`(ARM 64비트)를 지원합니다. 설치·업데이트 시 미리 빌드한 이미지 중 해당 기기에 맞는 하나만 내려받습니다. Home Assistant의 다운로드·압축 해제 진행률을 활용하며 표시 방식은 Home Assistant/Supervisor 버전에 따라 다릅니다.

## MP4 저장과 다운로드

새로 완료하는 변환은 qcamera의 H.264와 f·e의 HEVC를 재압축 없이 MP4로 포장하고, 압축 프레임·디코더 헤더·프레임 수·로그 시간 검증 후 원본 TS·HEVC를 정리합니다. 실패한 영상은 원본을 유지합니다. rlog.zst는 그대로 보관합니다. 자동 변환을 끄면 업로드 파일을 보관하고 수동 변환 후 MP4로 저장합니다. HEVC 재생에는 브라우저·기기의 지원이 필요하며 재생 실패 시 저화질 영상으로 전환합니다. 검증은 압축 데이터와 헤더의 SHA-256 및 패킷 시간·수를 비교하며, 전체 영상을 디코딩하지 않습니다. 원본 자체의 모든 디코딩 오류를 검사하는 방식은 아닙니다.

진행 막대는 준비부터 큰 압축·저장이 끝날 때까지 표시됩니다. 영상이 있는 로그는 준비·압축 해제 0~4%, 로그 읽기 4~45%, 프레임 분석 45~60%, 카메라 읽기·포장·검증 60~80%, 그래프 생성·JSON 변환·압축 저장·재생 데이터 정리 80~100%로 나눕니다. 영상이 없으면 그 비중을 읽기·분석·저장에 재분배합니다. 읽은 바이트, 처리한 프레임·샘플, 저장한 바이트에 따라 약 1초마다 갱신하며 막대는 부드럽게 이어집니다. 각 작업의 실제 이름과 전체 진행률을 표시합니다. 큰 파일의 압축·원자적 저장이 끝나면 100%가 되고, 마지막 요약 저장·결과 등록에서는 막대를 숨기고 빛 효과만 유지합니다. 이 마지막 구간에는 무거운 변환 작업을 남기지 않습니다. 이 비율은 작업량 기준 단계 가중치이며 남은 시간의 백분율은 아닙니다.

구간의 ⋯ 메뉴에서 **다운로드**를 누르면 팝업에서 파일과 MP4·원본 형식을 고릅니다. **전체 선택**과 **선택 해제**로 ZIP에 포함할 파일을 조절합니다. 각 파일 옆의 **받기**는 ZIP 없이 해당 파일만 받습니다. 여러 구간을 선택한 경우에는 **개별 받기**를 펼쳐 구간별 파일을 받습니다. f·e는 HEVC, q는 TS로 재압축 없이 다시 만들며 화질은 같지만 업로드 파일과 바이트·해시까지 동일하지는 않습니다. 선택한 여러 파일은 ZIP으로 스트리밍하고, 서버에 다운로드용 복사본을 보관하지 않습니다. 선택 모드의 다운로드도 같은 팝업을 사용하며 선택한 최대 150구간을 묶습니다. 없는 카메라는 제외합니다. MP4는 보관 영상이므로 유일한 MP4는 변환 데이터 제거로 삭제하지 않습니다.

선택 모드에서는 주행 카드의 체크박스로 주행 전체를, 구간 체크박스로 개별 구간을 고르며 일부 선택은 −로 표시합니다. 하단 작업 바의 **다운로드**를 눌러 파일과 형식을 고릅니다. 구간 ⋯ 메뉴·재생 화면의 다운로드 팝업은 해당 구간의 파일과 형식만 선택합니다.

## 저장공간 설정

현재 상태, 아카이빙 기본 설정, 실행·고급 설정, 현재 설정 요약 순서로 확인합니다. 프리셋에 없는 기존 값도 유지하며, 요약을 검토한 뒤 저장합니다. 미저장 변경으로 수동 전체 이동·복사를 실행하지 않습니다. 구간 태그로 분류하고 장면 북마크로 특정 시점을 찾을 수 있으며, 삭제 보호는 별도의 핀 고정을 사용합니다.

**Google Drive MOVE는 로컬 확장 저장공간입니다.** Drive MOVE와 로컬 원본 삭제 허용을 함께 설정하면 로컬 최대 사용량은 **소프트 리밋**으로 동작합니다. 아카이빙이 켜져 있을 때 한도 또는 아카이빙 시작 기준에 도달하면 기존 아카이버에 백그라운드 이동을 요청합니다. 둘 다 설정한 경우 더 낮은 값을 기준으로 합니다. 다른 업로드의 남은 예약, 임시 파일과 **100 MiB 안전 여유**를 확보할 수 있으면 한도를 일시적으로 넘어도 업로드를 받습니다. 업로드 요청이 Drive 전송 완료를 기다리지는 않습니다.

MOVE는 원격 전송·무결성 검증·저장 기록 확정 후 해당 로컬 파일만 지웁니다. 최소 보관 기간·고정·사용 중 보호·배치 제한을 유지하며 중복 실행하지 않습니다. Drive 장애나 검증 실패가 있어도 원본과 기록을 보존하고, 물리적 여유가 충분하면 업로드를 계속 받습니다. 공간이 실제로 부족하면 기존 기록을 지우지 않고 신규 업로드를 거부합니다. 아카이빙을 끄면 이동하지 않습니다. 이 경우에도 Drive MOVE 설정의 소프트 한도는 유지되며 물리적 디스크 여유가 업로드 허용 기준입니다.

Drive로 옮긴 기록은 **목록·재생·다운로드에 그대로 남습니다.** 자동 로컬 정리는 Drive 파일이나 Drive 파일이 연결된 기록을 삭제하지 않습니다(COPY 사본도 보호). 원격 삭제는 사용자가 **완전 삭제**를 명시한 경우에만 예약합니다. 출처를 확인할 수 없는 이전 버전의 원격 삭제 대기는 자동 실행하지 않습니다.

[화면별 설정 안내](DOCS.md#저장공간-화면-읽기)를 참고하세요.
