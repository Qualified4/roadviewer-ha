# Road Viewer

Openpilot 로그와 전방 카메라 영상을 Home Assistant 안에서 함께 재생하는 앱입니다.

- 여러 구간 업로드, 중복 로그 건너뛰기, 영상 나중에 추가
- 자동·수동 변환과 최대 4개 동시 처리
- 영상·주행 상황·차량 정보 그래프의 동기 재생
- 차선·모델 경로·레이더 감지점의 영상 겹쳐보기
- 좌우·상하 배치, 화면 폭 조절 팝업, 표시 설정 저장
- 그래프 선택·순서 변경·초기화와 카메라 설치 정보 확인
- 원본 TS 보관 여부 선택, TS 또는 MP4 다운로드
- 보관 파일·변환 용량 표시, 변환 데이터 제거, 완전 삭제, 미완료 업로드 정리

**파일 추가 → 업로드 → 변환 완료 후 재생** 순서로 사용합니다. 로그만 올릴 수도 있지만 영상만 단독으로 등록할 수는 없습니다.

Home Assistant Ingress를 통해 접근하며 별도 외부 포트는 노출하지 않습니다. 원본 로그·영상·변환 결과는 **Home Assistant 앱 백업에서 제외**됩니다. 보관할 원본은 별도로 유지하세요.

자세한 사용법은 앱의 **문서** 탭 또는 [DOCS.md](DOCS.md), 버전별 변경은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.
