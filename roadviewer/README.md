# Road Viewer

Openpilot 로그와 전방 카메라 영상을 Home Assistant 안에서 함께 재생하고 분석하는 앱입니다.

## 빠른 시작

**파일 추가 또는 드래그 앤 드롭 → 업로드 → 변환 → 재생** 순서로 사용합니다. 자동 변환은 기본으로 켜져 있습니다.

같은 구간의 `rlog.zst`와 `qcamera.ts`를 선택하세요. 로그만 올릴 수도 있지만 영상만 단독으로 등록하거나 MP4를 직접 업로드할 수는 없습니다. 여러 구간을 함께 선택할 수 있으며, 모바일 파일 선택창이 다중 선택을 지원하지 않으면 하나씩 추가하세요.

## 주요 기능

- 영상·주행 상황·차량 정보 그래프의 동기 재생과 최대 4배속
- 차선·모델 경로·레이더 감지점의 영상 겹쳐보기
- 자동·좌우·상하 배치, 화면 폭 조절, 상단 접기와 고정 재생바
- 그래프 20종의 선택·순서 변경·초기화와 카메라 설치 정보 확인
- 자동·수동 변환, 최대 4개 동시 처리, 원본 TS 보관 여부 선택
- 영상 나중에 추가, 누락된 원본 TS 복원, 로그·영상 다운로드
- 구간별 핀 고정, 일괄 변환·제거·완전 삭제, 저장공간 한도와 자동 정리
- 선택적 HTTPS 장치 업로드와 페어링

## 파일을 정리할 때

**제거**는 분석·그래프와 다시 만들 수 있는 MP4를 지우고 원본 로그·TS 및 유일한 MP4를 유지합니다. **완전 삭제**는 해당 구간의 파일을 모두 지웁니다.

설정 맨 아래 **로그 선택**을 누르면 일괄 관리 팝업이 열립니다. 고정된 구간은 기본적으로 제거·완전 삭제에서 제외되며, **고정 항목도 삭제**를 켜면 포함됩니다. 팝업을 다시 열 때는 꺼짐으로 돌아갑니다.

웹 UI는 Home Assistant Ingress로 접속합니다. 외부 장치 API는 기본적으로 꺼져 있으며 필요한 경우에만 앱 내부에서 HTTPS 포트를 설정합니다.

**원본 로그·영상·변환 결과는 Home Assistant 앱 백업에서 제외됩니다.** 보관할 원본은 별도로 유지하세요. 처리·저장 정책·장치 인증 설정은 백업에 포함됩니다.

자세한 사용법은 앱의 **문서** 탭 또는 [DOCS.md](DOCS.md), 버전별 변경은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.
